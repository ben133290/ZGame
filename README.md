<!-- GETTING STARTED -->
## Getting Started

### Prerequisites

* Python 3.9 or newer
* Any modern terminal application (a terminal with truecolor support gives the best colours)
### Installation

1. Clone the repo
```sh
   git clone https://github.com/ben133290/ZGame.git
   cd ZGame
```
2. (Optional) Create and activate a virtual environment
```sh
   python -m venv .venv
   source .venv/bin/activate   # on Windows: .venv\Scripts\activate
```
3. Install the dependencies
```sh
   pip install textual
```
4. Start the game
```sh
   python main.py
```
